# 📦 `AugmentedDualTransformDataset`에서의 Transform 적용 원리

`AugmentedDualTransformDataset`은 원본 이미지와 증가 이미지에 대해 **transform 적용 여부를 변동**하여 처리합니다.

---

## ✅ 1. 데이터셋 구조

| 구매     | 저장 위치                 | 설명                                     |
| ------ | --------------------- | -------------------------------------- |
| 원본 이미지 | `self.data`           | 실제 이미지 파일 경로 (cv2로 로딩됩니다)              |
| 증가 이미지 | `self.augmented_data` | transform이 **이미 적용된** 이미지 (메모리에 저장됩니다) |

---

## ✅ 2. Transform 관련 파래머터

| 파래머터 이름                   | 역할                                                                |
| ------------------------- | ----------------------------------------------------------------- |
| `default_transform`       | 일반 클래스에 적용할 transform 함수                                          |
| `custom_transform`        | 튼정 클래스(예: "Etc")에만 적용할 transform 함수                               |
| `use_custom_condition_fn` | 어느 클래스에 `custom_transform`을 적용할지 판단하는 조건 함수 (`class_name → bool`) |

---

## ✅ 3. Transform 적용 위치

### ⛔ 원본 이미지 (`self.data`)

* transform이 **적용되지 않음**
* `__getitem__()`에서 원본 이미지는 `cv2.imread()`로 로딩 후, 그대로 반환

### ✅ 증가 이미지 (`self.augmented_data`)

* 클래스별 상태를 고려해, `target_count` 기준으로 증가 진행
* 이때 `default_transform` 또는 `custom_transform`을 **즉시 적용해서 메모리에 저장**
* 후에 `__getitem__()`에서 그대로 받아서 사용

---

## ✅ 4. Transform 결정 로지

```python
transform_to_use = (
    custom_transform if use_custom_condition_fn and use_custom_condition_fn(class_name)
    else default_transform
)
```

* 지정된 클래스 이름이 `use_custom_condition_fn`에 해당하면 `custom_transform`을 적용
* 그것이 아니면 `default_transform`을 적용

---

## ✅ 요약

| 구매     | Transform 적용       |
| ------ | ------------------ |
| 원본 이미지 | ❌ 무적용              |
| 증가 이미지 | ✅ 적용해서 메모리 구조 후 저장 |

---

❌ 원본을 그대로 두고, 증가에만 transform을 적용하기 때문에 **복잡하게 사용자가 그대로 transform 함수를 만들면 된다**는 점이 특징입니다.
